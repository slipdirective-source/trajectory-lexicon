# The Trajectory Lexicon

A fail-closed language for consequential discrimination, trajectory mapping, bounded intervention, agency, safety, responsibility, and governed execution.

**Core discipline:** never erase a distinction consequence supports; never manufacture one it does not; never spend the capacity to detect error, correct, recover, or reconstruct without explicit warrant.

## Status

Closed Core 1.4 — operationally closed, not epistemically final. Every listed issue has a deterministic procedure, a domain-parameterized procedure, an empirical resolution path, an external normative boundary, or an explicit fundamental-open classification. A contradiction, untyped authority path, unhandled transition, or new consequential distinction automatically reopens the section it defeats.

## Relation to GuardianLink

The Lexicon is the specification layer; GuardianLink is the enforcement engine. The Lexicon says what "governed" means — typed speech acts, admissibility, safety states with bound responses, trust separation, provenance requirements. GuardianLink is the machine that refuses to act outside those bounds. See the [guardianlink-lexicon](https://github.com/slipdirective-source/guardianlink-lexicon) integration repo for the coupling layer.
